# DX3rd Combat Board 画像クイックガイド

## 1. 盤面を作る

![戦闘ボード全体](assets/manual-board.png)

1. 左上の「共有ルーム」から招待リンクをコピーします。
2. 「追加」でエンゲージ、PC、エネミーを作成します。
3. 「描画」で円、矩形、地形、矢印、両矢印を作成します。
4. 中央の盤面で駒やエンゲージをドラッグします。選択中に表示される白いハンドルをドラッグすると大きさを変更できます。
5. 駒の上にはダイス補正、C値補正、攻撃力補正、バッドステータス、累積ダメージが表示されます。
6. 右側の行動値一覧で手番を管理します。
7. ココフォリアと併用するときは、右上の「小窓表示」を押し、小窓内の「盤面」「行動値」を切り替えて操作します。

## 2. 駒を設定する

![駒の設定パネル](assets/manual-settings.png)

1. 駒をクリックすると左側に設定が表示されます。
2. 駒または一覧を右クリックすると、同じ項目を素早く設定できます。
3. 行動値、ダイス補正、C値補正、攻撃力補正を入力します。
4. 累積ダメージは `10`、`-5`、`10+3-2` のように入力して「適用」を押します。
5. バッドステータスは複数選択できます。
6. 邪毒を選択した場合は「邪毒 Lv」を設定します。

## 3. FS判定を管理する

1. 戦闘ボード左上の「FS判定」を押します。
2. FS名、終了進行値、ラウンド制限、技能、難易度、最大達成値を設定します。
3. 参加者の達成値を入力し、候補として表示された進行値を確認して履歴へ追加します。
4. 進行バーのピンでイベント位置を確認します。到達したイベントは、GMが「公開」を押した時点で内容と変更後の判定条件が反映されます。
5. 画面下部の「ダイス表作成」で結果表を作り、「コマンドをコピー」からココフォリアへ貼り付けます。
6. ダイス表は端末内に保存されます。別端末へ移す場合はJSON書出・読込を使います。
